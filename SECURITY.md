# Security policy

Report suspected vulnerabilities through this repository's
[private vulnerability reporting form](https://github.com/alapierre/ksef-client-java-mf-fork/security/advisories/new).
Include the affected client version, a description of the impact and a minimal
reproduction using synthetic data.

Do not include real invoices, taxpayer data, KSeF tokens, private keys or signing
credentials in a report. If the private form is unavailable, contact the
maintainer at [al@alapierre.io](mailto:al@alapierre.io). Please avoid public issues
for details of an unpatched vulnerability.

Security fixes target the latest stable release of this fork. Older releases
do not have a separate maintenance commitment; users should upgrade to the
latest stable version. Report vulnerabilities here even if you found them in an
older release.

The library's major version follows the KSeF API generation. Consult the release
notes for compatibility changes within the `2.x` line.
